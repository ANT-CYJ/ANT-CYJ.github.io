这个博客之前是个 GitBook 3.2.3 老站(2021 年建的),维护了 1 篇原创就断更了。

2026 年重启,这次选 [Astro](https://astro.build) 重做,理由:

- **写起来不费力** — Markdown + Frontmatter,10 分钟一篇
- **零运维** — push 到 GitHub 自动部署到 `ant-cyj.github.io`
- **现代** — 移动端、SEO、RSS 都到位

接下来会写这几类:

1. **复盘总结** — 项目过程、踩坑、决策
2. **知识性内容** — 学到的概念、原理
3. **好用的工具** — 工具/库的第一手经验
4. **想法** — 观察、观点

不追求更新频率,只追求"当下想到的就记下来"。
