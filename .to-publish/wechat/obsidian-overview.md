## 一句话定论

> **Obsidian 不是笔记软件,是本地优先的 Markdown IDE。** 它对你知识库做的最重要的事,不是"帮你写笔记",而是**让笔记互相认识**。

## 8 个月转折

装了 Obsidian 头 3 个月,我当 OneNote 用 — 写待办、抄链接、堆 `.md`。**完全没 get 到它好在哪。**

第 4 月转折:把 B 站技术视频全存进去,加 `[[]]` 链接。**一周后打开"Transformer"笔记,Backlinks 自动列出 7 篇提到它的笔记。**

那一刻我懂:双向链接不是"我链接别人",是"别人会回链我"。

## 7 特性,只离不开 3 个

**1. 双向链接 `[[wikilinks]]`**
- A 写 `[[B]]` → B 自动感知被链,Backlinks 列出 A
- 单向 = 信件(对方不知道);双向 = 社交网络(双方都看到)
- **知识会自己织网,反链即上下文**

**2. 本地纯文本 `.md` 文件**
- vault 就是硬盘上的一堆 `.md` 文件
- 解锁两个能力:(1) Git 版本管理 (2) **AI 直接读写**
- 反 SaaS 路线 — 你拥有你的数据,工具只是渲染器

**3. 插件生态**
- 数千插件,但**别装太多,5-8 个精品顶 50 个闲置**
- 我只装:Dataview / Excalidraw / Local REST API / Claudian / Hover Editor

## 建筑师 vs 室内设计师

AI 时代用 Obsidian,最该想清楚的问题:**它跟 Cursor/Claude Code 的边界在哪?**

| 角色 | 工具 | 干什么 |
|---|---|---|
| 🏗️ 建筑师 | Cursor / Claude Code | 批量建库、建链接 |
| 🎨 室内设计师 | Obsidian AI 插件 | 精装修已有笔记 |

**我的工作流:** Claude Code 建库 + Claudian 改写。

## 同步方案:7 种只推 1 种

| 方案 | 场景 | 成本 |
|---|---|---|
| OneDrive 原生 | 纯桌面 | 免费 |
| iCloud | 苹果生态 | 免费 |
| Obsidian Sync 官方 | 全平台最省心 | $4/月 |
| **Remotely Save + COS** | ✅ **跨平台首选** | **6 元/年** |

## 收尾:Obsidian 是认知基础设施

**3 条给新手:**
1. 别看教程,先装上用一周
2. 别装几十插件,3-5 个起步
3. **把 vault 放进 Git** — 跨设备 + AI 直接读写零成本

**1 条给老用户:**
试试让 AI Agent 直接维护 vault — `Read/Write/Edit` 你的 `.md`,让它帮你建笔记、加链接。**2026 年最被低估的个人生产力倍增器。**
