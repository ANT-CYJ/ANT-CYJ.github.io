## 正文(适合微信公众号群发)

**FDE 不是"高级实施",是"会写代码的业务翻译官"**

上一篇 FDE 概览讲 FDE 是什么(避弹衣 + 拉登 + 帕兰提尔 Delta/Echo 模式),这篇讲实操:

**1. 工程师转型 FDE 的 3 个硬动作**(过去 6 个月):
- 每月做 1 次"客户现场模拟":朋友扮演甲方,你在 30 分钟内不写代码拆需求
- 选 1 个行业深挖 6 个月(金融 / 医疗 / 制造 / 零售),看年报 / 招股书学商业语言
- 做 1-2 个非工作项目,简历从"我用什么技术"变成"我帮客户解决什么问题"

**2. FDE 一天的工作节奏**:
- 09:00 客户早会(今日目标对齐,跳过一天白干)
- 09:30 需求拆解(1h)→ 10:30 代码/部署(2.5h)
- 14:00 客户同步(30min)→ 15:00 改进 + 沉淀(2h)
- 17:00 内部 Sync + 18:00 文档 + 18:30 复盘(给客户/自己/公司三方)

**3. FDE 一周的工作节奏**:
- 周一:客户现场 → 周二:开发 → 周三:Demo → 周四:改进 → 周五:周复盘

**4. 13 项技能按 4 层分层**:
- 核心 6 项:Python / SQL / Docker / REST API / CI/CD / 云平台
- AI 工程 4 项:Agent Skills / Context Engineering / Vibe Coding / Harness
- 业务沟通 1 项:技术语言 ↔ 商业语言翻译(关键差距)
- 行业深度 2 项:1 个行业 + 1 个法规

**6 个月从工程师到 FDE** 的最小可行路线,见完整博客。
