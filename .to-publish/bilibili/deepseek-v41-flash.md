| 维度 | 方案 A:自动路由 | 方案 B:独立直连 |

## 6 条短板(必看)

1. **过度思考** — 简单问题易写冗长推理
2. **复杂任务 token 消耗更高** — 多 Agent 场景比 V4 多 **36%**
3. **长上下文仍有短板** — 长文写作前后数字不一致
4. **非视觉端到端任务** — 完成时间无明显变化
5. **刚上线边界未验证** — 复杂 Agent 循环需生产环境踩坑
6. **PDF 需转图** — API 不支持直接上传 PDF

**关键洞察**:"更便宜"指**单价 + 推理效率**下降,但**多 Agent 场景总花费可能更高**。
